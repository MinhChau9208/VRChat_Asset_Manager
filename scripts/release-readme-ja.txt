VRChat Asset Manager
====================

VRChat 用アセット（アバター、髪型、衣装、ギミックなど）を管理する個人用カタログです。
何を買ったか、どんな見た目か、PC のどこにあるか、BOOTH のページはどこか、がすぐにわかります。

画面右上の言語ボタンで日本語 / English を切り替えられます。


起動
----
1. このフォルダを好きな場所に展開します（例: ドキュメント\VRChatAssetManager）。
   zip の中から直接実行しないでください。
2. VRChatAssetManager.exe をダブルクリックします。
3. ブラウザでアプリが開きます。開かない場合は http://127.0.0.1:47380 を開いてください。

初回は「Windows によって PC が保護されました」と表示されることがあります。
このアプリはコード署名されていないため、「詳細情報」→「実行」をクリックしてください。


起動中
------
アプリはタスクトレイ（画面右下の時計の横。^ の中に隠れていることもあります）に常駐します。
アイコンをクリックするとアプリをもう一度開けます。
右クリックで「データフォルダを開く」「終了」が選べます。

起動中にもう一度 exe をダブルクリックすると、ブラウザが開くだけです。


終了
----
タスクトレイのアイコンを右クリック →「終了」。


はじめに
--------
- 左のサイドバーの「スキャン・確認」→ アセットフォルダ（例: D:\VRChat Assets）を追加
  →「スキャン」。見つかったアセットは下書きになり、承認・編集・無視を選べます。
- 「アセットを追加」から 1 つずつ登録することもできます。
- 「BOOTH から取得」で、BOOTH のリンクから名前・作者・カテゴリ・画像が入力されます。

アプリがアセットのファイルを移動・名前変更・削除することはありません。


データ
------
アプリが保存するものはすべて exe の隣の「data」フォルダにあります:

    data\app.db       ライブラリ
    data\previews\    サムネイル画像
    data\backups\     更新前に自動で作られるバックアップ
    data\logs\        app.log（問題が起きたときに役立ちます）

バックアップ: 「data」フォルダをコピーします。
別の PC へ移す: VRChatAssetManager フォルダごとコピーします。


アップデート
------------
アプリを終了し（タスクトレイ →「終了」）、VRChatAssetManager.exe を新しいものに置き換えます。
「data」はそのまま残してください。データベースは更新前に自動でバックアップされます。


困ったとき
----------
- 「Cannot listen on ...」: 別のプログラムがポート 47380 を使っています。そのプログラムを
  閉じるか、コマンドプロンプトから次のように起動してください:
      set PORT=47381 && VRChatAssetManager.exe
- その他: エラーはメッセージボックスに表示され、data\logs\app.log にも記録されます。
